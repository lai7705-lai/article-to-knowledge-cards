# make-knowledge-cards

長文裡的重點和重複敘述混在一起，複習時往往得重新翻找。這個 Codex 技能會把文章整理成可獨立複習的知識卡片，幫助你快速回顧概念、理解條件，並用原文內容自測。

## 主要功能

- 接受貼在對話中的文字，以及 Codex 可讀取的本機 Markdown（`.md`、`.markdown`）或純文字（`.txt`）檔案。
- 優先挑選與文章主旨或實際應用有關的概念、關係和步驟，合併重複敘述。每張卡片聚焦一個重點，通常產出 5～8 張。重點不足時會減少張數並簡短說明。
- 每張卡片包含標題、核心知識、簡明解釋，以及原文例子或可從原文作答的自測問題。整理時會保留原文中的適用條件與不確定性。
- 在 Codex 對話中回傳 Markdown。可以指定輸出語言，預設採用原文語言。若素材是網頁或 PDF，請先貼上文字，或將文字存成支援的本機檔案。

## 安裝方法

1. 將這個專案下載或複製到本機，保留 `skills/make-knowledge-cards/` 的目錄結構。
2. 在 Codex 中開啟專案根目錄，確認可讀取 `skills/make-knowledge-cards/SKILL.md`。

此專案以技能指令運作，開啟專案後即可使用，不需要安裝套件或執行建置命令。

## 使用方法

在專案的 Codex 對話中，請 Codex 依照 `skills/make-knowledge-cards/SKILL.md` 整理素材。你可以在指令後直接貼上原文，或提供本機檔案路徑。

以下指令使用專案內附的 Markdown 檔案。

```text
請依照 skills/make-knowledge-cards/SKILL.md，把 work/card-checks/cache.md 整理成繁體中文知識卡片。
```

## 輸入與輸出範例

### 輸入

```text
請依照 skills/make-knowledge-cards/SKILL.md，把下面這段文字整理成繁體中文知識卡片。

快取項目有效期為 60 秒。逾期後，下一次讀取會重新從來源取得資料。
```

### 可能的輸出

原文只有一個可獨立複習的重點，因此產生 1 張卡片。

#### 快取逾期後重新讀取來源

- **核心知識** — 快取項目有效期為 60 秒。
- **簡明解釋** — 逾期後，下次讀取會重新從來源取得資料。
- **自測問題** — 快取項目逾期後，下次讀取會從哪裡取得資料？
